## 🚀 **How to Use**

### **Access the Dashboard**
```
http://localhost:5000
```

### **Navigation**
- **Live Monitor**: Real-time system health
- **Weekly Report**: 7-day performance trends
- **Settings & Export**: Export reports, adjust refresh rate

### **Key Interactions**
- **Click System Name** → Rename your system
- **Click "?" Tooltips** → Learn what each metric means
- **Keyboard Shortcuts**:
  - `R` = Refresh data
  - `V` = Toggle detailed view
  - `ESC` = Close modals

### **Quick Actions**
- **🧹 Clear Memory** - Free up RAM
- **❄️ Cool Down CPU** - Throttle background processes
- **⚡ Boost Mode** - Optimize for performance
- **🌱 Eco Mode** - Save energy

## 🔧 **Technical Architecture**

### **Backend (Python/Flask)**
- Real-time system metrics via `psutil`
- AI insight generation (14 different algorithms)
- Mock weekly reports
- Export simulation endpoints

### **Frontend (Vanilla JS)**
- No frameworks - pure JavaScript
- 3-second auto-refresh
- Keyboard shortcuts
- Modal system
- Toast notifications

### **Data Flow**
```
System Hardware → psutil → AI Analysis → JSON API → Frontend → UI Updates
```

## 📝 **API Endpoints**

| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/json` | GET | Full system metrics + AI insights |
| `/api/name` | GET/POST | Get/set custom system name |
| `/api/action` | POST | Execute optimization actions |
| `/api/report/weekly` | GET | Get 7-day performance summary |
| `/api/report/export` | POST | Export report as PDF/CSV |
