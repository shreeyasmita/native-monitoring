# 🎯 Quick Navigation Bar Guide

## 🖥️ What You'll See

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ ✨ LizzyMonitor  📊 Dashboard  📈 Analytics  🏆 Health  ☁️ Cloud  📋 Reports │
```

---

## 📌 Features & How to Use

### 1. **Logo (Left)**
- **Click:** Will scroll to dashboard section
- **Look:** Glows on hover
- **Shows:** "✨ LizzyMonitor" brand name

### 2. **Navigation Menu (Center)**
Five quick navigation options:

| Icon | Name | Goes To |
|------|------|---------|
| 📊 | Dashboard | CPU/Memory gauges |
| 📈 | Analytics | Peak usage, trends |
| 🏆 | Health | System health score |
| ☁️ | Cloud | Cloud integration |
| 📋 | Reports | Report generation |

**How to Use:** Click any item to smoothly scroll to that section

### 3. **Real-Time Stats (Right of Center)**
Shows live system metrics updated every 3 seconds:
- **CPU: XX%** - Current CPU usage
- **RAM: XX%** - Current memory usage
- **Health: XX** - System health (0-100)

No action needed - just information!

### 4. **Theme Selector (Far Right)**
- **Button:** "🎨 Theme"
- **Click:** Opens dropdown with 7 theme options
  - 🌙 Dark (default)
  - ☀️ Light
  - 🌊 Ocean
  - 🌲 Forest
  - 🌅 Sunset
  - ⚡ Cyber
  - 🌸 Sakura

**How to Use:**
1. Click "🎨 Theme" button
2. Select desired theme
3. Dashboard instantly changes theme

## 📞 Support

**If something doesn't work:**
1. Refresh the page (Ctrl+F5)
2. Check your browser console (F12)
3. Try a different theme
4. Clear browser cache

**If navbar looks broken:**
- Ensure JavaScript is enabled
- Check browser compatibility (Chrome, Firefox, Safari all work)
- Try zooming out (Ctrl+- or Cmd+-)
